# Crop Disease Classification on ARM Cortex-M33

## Project

Lightweight Edge AI System for Crop Leaf Disease Classification on Low-Power Embedded Devices.

## Hardware

- STM32 NUCLEO-H533RE
- OV2640 Camera

## AI Model

- MobileNetV2
- TensorFlow
- TensorFlow Lite (INT8)

## Dataset

PlantVillage
- 54,303 Images
- 38 Classes
